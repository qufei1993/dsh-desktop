# 推送前验证 DSH Desktop 改动

[English（权威版本）](SKILL.md) | 简体中文（人工审阅）

检查完整的待推送 diff，并保留无关工作。始终运行 `npm run verify`；对于当前小型项目，它是有意设置的共同本地基线。

根据受影响范围增加检查：

- 内置运行时准备、官方 DSH 启动、CLI 解析、包管理器行为或 DSH 边界：准备运行时后运行 `npm run test:official`。
- 打包配置、安装包资源、Electron 启动、安装器行为或安装包 UI：构建当前平台安装包，并运行 `npm run test:packaged`。
- UI 行为：运行聚焦测试；安装包 E2E 未覆盖时，记录截图或手工交互结果。
- 发布元数据或 Changelog 提取：运行聚焦发布测试；存在真实构建产物时，对其执行相关元数据命令。
- 平台专用代码：运行当前主机可以执行的证据，并说明哪些必需平台只能由 CI 覆盖。

没有理由时不要重复已经通过的命令。不得削弱检查、删除断言，或者只为隐藏失败而缩小测试范围。报告实际执行的命令、结果和无法运行的检查。
