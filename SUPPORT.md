# Support

## Where to ask

- Reproducible DSH Desktop defects: use the [Bug Report](https://github.com/qufei1993/dsh-desktop/issues/new?template=bug_report.yml).
- Feature or user-experience proposals: use the [Feature Request](https://github.com/qufei1993/dsh-desktop/issues/new?template=feature_request.yml).
- Security vulnerabilities: report them privately according to the [Security Policy](SECURITY.md).
- Questions about official DSH models, keys, sessions, Skills, MCP, or services: use the official DeepSeek Harness support channel.

## Before opening an issue

Confirm that you are using the latest DSH Desktop release and search existing issues. If the problem remains, record the operating system, CPU architecture, DSH Desktop version, selected DSH version, reproduction steps, and complete error text.

Do not upload API keys, access tokens, signing material, real session content, or the complete `DSH_HOME` directory. Remove usernames, paths, and business data from logs before sharing them.

## Support expectations

This is a community-maintained open-source project. It does not provide a service-level agreement, private one-to-one support, or a guaranteed response time. Maintainers prioritize security issues, data risks, startup failures, and high-impact regressions.
